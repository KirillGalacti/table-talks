# Стол переговоров — «Арена переговоров»

Тренировка в формате пошаговой мини-игры: пять условий сделки на столе, шесть карт действий, жетоны уступок и AI-поставщик на YandexGPT. Путь: настройки → «Как устроен стол» → стол (до 8 ходов) → итог → краткий и полный отчёт → история тренировок.

Отдельный проект; стек и Yandex Cloud — те же, что в `free-talking` / `ai-negotiation-arena`.

## Стек

- React 19 + Vite + TypeScript, Tailwind CSS 4, шрифты Montserrat Alternates и Nunito Sans;
- Node.js + Express 5 + TypeScript (tsx);
- YandexGPT через OpenAI-совместимый API: `yandexgpt-5-lite` — реплики поставщика, `yandexgpt/latest` — текст оценки.

## Запуск

Нужен Node.js 20+ и файл `.env` в корне (ключи общего проекта уже перенесены):

```env
YANDEX_API_KEY=...
YANDEX_FOLDER_ID=...
API_PORT=3003
```

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте http://127.0.0.1:5180 (порты отличаются от соседних проектов, все можно запускать одновременно).

Прочее: `npm.cmd run build` — сборка, `npm.cmd start` — сервер со сборкой на `API_PORT`, `npm.cmd run test:unit` — тесты правил стола.

## Логика стола

- **Решения принимает сервер, модель только формулирует.** Скрытая карточка поставщика (`server/supplier-card.ts`) задаёт, что он может принять: 44 000 ₽ — только от 120 штук, полной отсрочки нет (мотив «График оплаты»), 7 дней — только при полной предоплате или по 48 000 ₽ (мотив «Срок производства»), 36 мес. гарантии — только по полной цене. Карточка не уходит в браузер.
- **Ход** (`POST /api/table/:id/turn`) детерминированно меняет стол: вопрос открывает мотив, якорь и пакет получают принятие или встречный пакет (ближайший приемлемый вариант), уступка при условии принимается, дополняется встречным условием или отклоняется. YandexGPT перефразирует ответ поставщика; если модель поменяла числа или потеряла условия, остаётся точная реплика из правил.
- **Жетоны**: каждый шаг ухудшения своей позиции стоит жетон; уступка без встречной ценности — «бесплатная» (доверие падает, оценка снижается). Отклонённая уступка жетон не списывает.
- **Идемпотентность**: повтор хода с тем же `clientEventId` возвращает тот же ответ — при обрыве связи «Повторить» не создаёт второй ход; до подтверждённого ответа карта и жетон не списаны.
- **Завершение**: «Резюме» после принятого пакета — сделка; после 8 ходов — итог по состоянию стола; «Выйти» — попытка не сохраняется как завершённая. Таймер — ориентир, он не обрывает тренировку.
- **Отчёт** (`POST /api/table/:id/report`): оценка 0–4 по наблюдаемым действиям выставляется правилами (рубрика навыка «Управление уступками», «Пакетные предложения» или «Работа с интересами»); YandexGPT пишет сильные действия, точки роста и вывод, при сбое модели используется детерминированный текст. «Другой достижимый пакет» считается по скрытым правилам поставщика.
- Столы хранятся на сервере в `data/tables.json`, история — в `localStorage` браузера.

## API

`POST /api/table/start`, `GET /api/table/:id`, `POST /api/table/:id/turn`, `POST /api/table/:id/time`, `POST /api/table/:id/finish`, `POST /api/table/:id/report`.

## Безопасность

`.env` и `data/*.json` исключены из Git; ключи Yandex Cloud используются только на сервере; входные данные ходов проверяются и ограничиваются на сервере.
